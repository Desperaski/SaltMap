# Fork Features & Modifications

Этот документ описывает изменения, добавленные поверх оригинальной версии мода SaltMap. Оригинальная документация (`rendering.md`, `minimap.md`) остается актуальной для базовой архитектуры.

## 1. Туман войны (Fog of War)
Добавлена система скрытия неисследованных областей карты (`Mod/FogOfWar.cs`).

*   **Принцип работы**: Карта разбита на сетку `128x128` (для производительности и мягких краев). Изначально вся карта черная.
*   **Раскрытие**: 
    *   Вокруг игрока (при движении) открывается круглая область с плавным градиентом на краях (используется `LinearClamp` для размытия пикселей).
    *   При убийстве босса открывается огромная область вокруг его локации.
*   **Взаимодействие с UI**: Неисследованные маркеры (предметы, NPC, враги) скрываются. Названия регионов (SSMap) появляются только если исследована область вокруг их текстовой метки (проверяется радиус `TextRevealRadius`).
*   **Сохранение**: Прогресс сохраняется **отдельно для каждого слота сохранения** в файлы `Mods/fog_<slotId>.dat` (автосохранение раз в 30 секунд и при открытии большой карты). При создании нового персонажа туман сбрасывается.
*   **Настройки в `SaltMap.ini`**:
    *   `fogOfWar=on|off` (вкл/выкл туман).
    *   `fogRadius=800` (радиус открытия вокруг игрока).
    *   `fogBossRadius=3000` (радиус открытия при убийстве босса).

## 2. Локализация интерфейса
Добавлена система перевода текстов мода (`Mod/Loc.cs`).

*   **Файлы**: Тексты лежат в `Mods/lang/*.txt` (в комплекте идут `en.txt` и `ru.txt`).
*   **Формат**: `КЛЮЧ=Значение`. Поддерживаются комментарии через `#`.
*   **Определение языка**: Мод автоматически синхронизируется с языком игры через Harmony-хук на `ConfigMgr.Read`. Если в `SaltMap.ini` параметр `modLang` пуст, мод берет ID языка из игры (например, `9` — официальный русский). Если указан `modLang=ru|en|...`, язык форсируется.
*   **Имена боссов**: В `ru.txt` добавлен словарь `BOSS_<флаг>`. 

## 3. Управление мода (JSON)
Вся логика нажатий мода вынесена из кода в отдельный файл `Mods/SaltMapControls.json` (`Mod/ModControls.cs`). 
*   Поддерживаются как клавиатура (по именам кнопок XNA), так и геймпад (по именам `BUTTON_A`, `R1`, `DPAD_UP` и т.д.).
*   Позволяет пользователю самому переназначить кнопки вызова миникарты и зума без пересборки мода.

## 4. Нативная отрисовка иконок геймпада в UI
**Проблема:** При выводе подсказок управления для геймпада в панели меню карты (`MenuMap.cs`) символы кнопок A, B, Y отображались корректно, а иконки стиков (Left/Right Stick) и крестовины (D-Pad) — пропадали.
**Решение:** В движке игры (`ProjectTower.hud.Text`) заложено два разных механизма подмены символов:
1. Строковые теги (`[a]`, `[b]`, `[y]`) рисуются как спрайты при `replaceIcons = 1`.
2. Спецсимволы стиков и крестовины (`\u02e5` - `\u0246`) обрабатываются нативным методом `GetSpecialRect` **только если** передан `replaceIcons = 2`.

Подсказки разбиты на две строки: `PadHint1` (стики, крестовина, `replaceIcons = 2`) и `PadHint2` (кнопки, `replaceIcons = 1`). Это позволило отрисовать все иконки нативно, без кастомного рендеринга.

## 5. Ускорение меню (MenuSpeedup)
**Проблема:** В оригинальной игре меню имеет долгую анимацию появления (около 1 секунды), во время которой ввод игнорируется, что делает управление "деревянным".
**Решение:** Добавлен Harmony-патч (`Mod/MenuSpeedup.cs`) на `MenuMgr.Update`. Патч принудительно устанавливает `transFrame = 2f` при начале перехода. Это заставляет игру **мгновенно завершить анимацию появления** и разблокировать ввод, полностью убирая задержку.

## 6. Изменения интерфейса карты (UI Tweaks)
*   **Расширение карты**: В `MenuMap.cs` уменьшены отступы, чтобы карта занимала больше места на экране.
*   **Две строки подсказок**: Текст управления внизу разбит на две строки, чтобы длинный русский текст не вылезал за края экрана.
*   **Прозрачность миникарты**: Настройка `minimapOpacity` в `SaltMap.ini` позволяет сделать миникарту полупрозрачной.

## 7. UDP-трекер
В оригинальном моде была фича отправки координат игрока на `localhost:47800`. Она была вынесена в опциональную настройку `udpTracker`. По умолчанию выключена (`off`).

## 8. Обновление инфраструктуры сборки и установки
*   **Сборка**: `tasks.targets` переписан для автоматического копирования мода, локализации и запуска патчера. Добавлен `Build.cmd` для сборки в один клик без Visual Studio (требуется только .NET SDK).
*   **Миграция настроек**: В `SaltMap.ini` добавлена логика автоматического дописывания новых ключей без сброса старых настроек пользователя.
*   **Установка**: `install.ps1` теперь копирует папку `lang`. `uninstall.ps1` удаляет только код мода, сохраняя пользовательские данные (карту `SSMap`, настройки, туман и переводы). Добавлен `uninstall.cmd`.
*   **Прогресс-бар**: В `Get-SsMap.ps1` кастомный прогресс-бар заменен на стандартный `Write-Progress`, чтобы он не ломался при изменении размера окна консоли.

## Обновленный список настроек `SaltMap.ini`
```ini
# Язык мода (en, ru). Если пусто — автоопределение из игры.
modLang=

# Прозрачность миникарты (0.1 - 1.0)
minimapOpacity=0.8

# Туман войны
fogOfWar=on
fogRadius=800
fogBossRadius=3000

# Отправка координат на localhost:47800
udpTracker=off
